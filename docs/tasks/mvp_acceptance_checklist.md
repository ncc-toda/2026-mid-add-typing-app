# MVP Acceptance Checklist

仕様: [`docs/specs/mvp.md`](../specs/mvp.md)

完了前に `just check` を通し、未完了があれば修正する。

## 画面

- [ ] タイトル: 世界観、スタート、統計、難易度別ハイスコア
- [ ] 難易度: 初級 / 中級 / 上級。制限時間は 60 秒である旨がある
- [ ] プレイ: Slack 風チャット、年収・残り時間・コンボ、打つ日本語とローマ字ヒント
- [ ] 結果: 年収、速度、正確性、ミス、最大コンボ、送信件数。タイトル / 統計 / もう一度
- [ ] 統計: 苦手キー / 指 / 動き。データ不足表示。リセットは確認ダイアログ付き
- [ ] 見た目は Pattern B（Arcade HUD）。比較用ナビは製品に出ない

## プレイ

- [ ] カウントダウンのあと 60 秒で打ち切る
- [ ] 全文一致で自動送信。送信キーは不要
- [ ] 未送信の途中返信は年収に入らない
- [ ] 誤りキーはミスになり、対象は進まない（強制正確）
- [ ] コンボは連続正解、ミスで 0
- [ ] 同じ難易度の問題がランダム順。プールを使い切ったら再シャッフルしてよい
- [ ] IME 変換なし（ローマ字を直接受け取る）
- [ ] `si`/`shi`、`ti`/`chi`、`tu`/`tsu`、`hu`/`fu`、撥音、長音のゆらぎを受け入れる
- [ ] 英数字・記号・改行は表示どおり

## スコアと保存

- [ ] 年収は `round(基礎額 × 速度係数 × 正確性係数)`。正確性係数は `0.7 + 正確性 × 0.45`
- [ ] タイトルに戻るとそのプレイの年収表示はリセットされる
- [ ] 難易度ごとのハイスコアが残る
- [ ] 初回アクセスで匿名 ID を生成しブラウザに保存する。個人情報は保存しない
- [ ] キー入力をプレイ中に都度サーバへ送らない。終了時にまとめて保存する
- [ ] 統計はキー・指・遷移の累計。入力 5 回未満はデータ不足
- [ ] 統計リセットはキー集計のみ。ハイスコアは残る

## コンテンツと環境

- [ ] 難易度ごとに問題が 12 件以上。世界観・口調・ボケが仕様どおり
- [ ] ローカル D1 と本番 D1 が分かれている
- [ ] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [ ] `just check` で lint、typecheck、test、build が走る
- [ ] Cloudflare Workers にデプロイされ、本番で一通りプレイできる
